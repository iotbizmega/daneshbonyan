# ایجنت تسهیلات دانش‌بنیان

منابع معتبر ایرانی را بررسی می‌کند (هر ۱۰ دقیقه در GitHub Actions، یا هر ۵ دقیقه روی سرور خودتان) و هر فراخوان، وام یا حمایت مالیِ تازه‌ی مربوط به شرکت‌های دانش‌بنیان را **یک بار** به ربات تلگرام (و در صورت خواست، به بله) می‌فرستد.

توجه: `api.telegram.org` از داخل ایران مسدود است، پس جایی که ایجنت اجرا می‌شود (GitHub Actions یا سرور) باید خارج از ایران باشد.

## دو روش اجرا

### ۱) بدون سرور: GitHub Actions (پیش‌فرض همین مخزن)
در هر ۱۰ دقیقه یک دور اجرا می‌شود و چیزی که قبلاً دیده شده در فایل `data/seen.db` روی شاخه‌ی `state` ذخیره می‌شود، پس تکراری ارسال نمی‌گردد.

یک بار این دو مقدار را در مخزن تعریف کنید: Settings → Secrets and variables → Actions → **New repository secret**
- `TELEGRAM_TOKEN` — توکن ربات
- `CHAT_ID` — شناسه‌ی چت/کانال (برای کانال با `-` شروع می‌شود)

اختیاری: `BALE_TOKEN`، `BALE_CHAT_ID`.
دو نکته: در پلن رایگان، مخزن **public** دقیقه‌ی نامحدود دارد ولی مخزن private سقف ۲۰۰۰ دقیقه در ماه دارد (با دورهای ۱۰ دقیقه‌ای از آن رد می‌شوید؛ در این حالت cron را روی `0 * * * *` بگذارید). همچنین زمان‌بندی GitHub ممکن است در ساعات شلوغ چند دقیقه عقب بیفتد.

### ۲) با سرور خودتان: Docker
    git clone <repo> && cd <repo>
    ./setup.sh
    docker compose up -d --build
    docker compose logs -f

قبل از `./setup.sh` در تلگرام گزینه‌ی **Start** را روی ربات بزنید؛ `setup.sh` چت‌ها را با `getUpdates` می‌خواند و تا پیامی ارسال نشده باشد چیزی برای انتخاب نیست. سپس توکن را می‌گیرد، چت را انتخاب می‌کند و `.env` را می‌سازد (این فایل در `.gitignore` است و هیچ کلیدی داخل کد یا مخزن نیست). دیتابیس حالت در `data/seen.db` و روی volume بیرون از کانتینر می‌ماند؛ برای ریست کامل، همان فایل را پاک کنید.

## منابع فعال (همه تست‌شده)
- **Bing News فارسی**: هشت پرس‌وجوی خبری درباره‌ی تسهیلات، فراخوان، حمایت مالی، صندوق نوآوری، اعتبار ویژه، وام، شتاب‌دهنده و پارک علم و فناوری.
- **فیدهای RSS معتبر**: خبرگزاری ایرنا، مهر، ایلنا و ستاد توسعه فناوری نانو (`news.nano.ir`).
- **سایت‌های رسمی با خزش HTML**: بنیاد ملی علم ایران (`insf.org`)، سازمان پژوهش‌های علمی و صنعتی ایران (`irost.org`)، پارک علم و فناوری دانشگاه تهران (`utstpark.ir`).

## کانال‌ها
`channels.txt` بیست‌ونُه کانال تأییدشده دارد: پانزده تلگرام، نه بله، پنج ایتا — وابسته به صندوق نوآوری، معاونت علمی، بنیاد ملی علم، پارک‌های علم و فناوری و شتاب‌دهنده‌ها. کنار هر خط با `#` توضیح نوشته شده و می‌توانید خط تازه اضافه کنید.

- **تلگرام** از پیش‌نمایش عمومی `t.me/s/<نام>` خوانده می‌شود (فقط کانال عمومی).
- **بله** از `ble.ir/s/<نام>`؛ چون کلاس‌های CSS این صفحه هَش می‌خورند، انتخابگرها بر پایه‌ی پیشوند نام کلاس ساخته شده‌اند.
- **ایتا** از `eitaa.com/<نام>` که سمت سرور رندر می‌شود؛ پیام‌های «سنجاق پیغام» حذف می‌شوند.
- **کشف خودکار**: لینک کانال‌ها داخل پست‌ها پیدا و اضافه می‌شود تا سقف `MAX_CHANNELS`. کانالی که در اولین بررسی واژه‌ی «دانش‌بنیان» نداشته باشد برچسب `no` می‌خورد و دیگر دنبال نمی‌شود؛ کانال ناپدید یا بسته هم با خطای ۴۰۴/۴۰۳ در همان نگاه اول کنار گذاشته می‌شود تا لاگ پر از تکرار نشود.

## چه چیزی حذف یا خاموش شد و چرا
- **روبیکا**: `rubika.ir` کاملاً با JavaScript رندر می‌شود و مسیر `/s/` صفحه‌ی تبلیغاتی برمی‌گرداند؛ راه قابل‌اعتمادی برای خواندن کانال عمومی بدون سرور واسط نبود، پس از کد و تنظیمات بیرون رفت.
- **Google News RSS**: از شبکه‌ی تست فقط صفحه‌ی تأیید یا خبرهای انگلیسی بی‌ربط می‌داد؛ جای آن Bing News فارسی آمد.
- **`inif.ir` و `isti.ir`**: از شبکه‌ی تست ما پاسخ ندادند (احتمال مسدودسازی منطقه‌ای). آدرس‌ها در `sources.json` با پرچم `"disabled": true` مانده‌اند؛ اگر سرور شما داخل ایران است، کافی است همین پرچم را بردارید. تا آن زمان اطلاعیه‌های این دو نهاد از کانال‌های رسمی تلگرام و بله‌شان گرفته می‌شود.
- دامنه‌های رهاشده یا نادرست (`ifdf.ir`، `ndfi.ir`، `nanopress.ir`) حذف شدند؛ `daneshbonyan.ir` سرویس استعلام است، نه منبع خبر.

## رفتار تضمین‌شده
- اجرای اول روی سرور و اولین نگاه به هر کانال فقط ثبت می‌کند و چیزی نمی‌فرستد؛ از دور بعدی فقط موارد تازه می‌روند.
- هر مورد با دو اثر انگشت (لینک + متن) شناسایی می‌شود، پس یک خبر حتی اگر از دو منبع مختلف بیاید فقط یک بار فرستاده می‌شود.
- خطای یک منبع یا کانال بقیه‌ی دور را متوقف نمی‌کند.
- محدودیت نرخ تلگرام رعایت می‌شود: در پاسخ ۴۲۹ به اندازه‌ی `retry_after` صبر، و خطاهای ۴xx غیرقابل‌تکرار رها می‌شوند.
- فقط متن‌های تازه‌تر از `MAX_AGE_DAYS` (پیش‌فرض ۷ روز) فرستاده می‌شوند.

## تنظیمات `.env`
- `TELEGRAM_TOKEN`، `CHAT_ID` — اجباری.
- `BALE_TOKEN`، `BALE_CHAT_ID` — اختیاری؛ اگر پر باشند یک نسخه به بله هم می‌رود. آدرس پایه‌ی API از مستندات رسمی `https://tapi.bale.ai` است و با `BALE_API_BASE` قابل تغییر است.
- `INTERVAL_SECONDS` (پیش‌فرض ۳۰۰)، `MAX_CHANNELS` (۱۵۰)، `MAX_AGE_DAYS` (۷).
- `LLM_BASE_URL`، `LLM_API_KEY`، `LLM_MODEL` — فیلتر هوشمند اختیاری برای رد کردن خبرهای بی‌ربط. با هر سرویس سازگار با OpenAI کار می‌کند (مثلاً `https://api.groq.com/openai/v1` با مدل `llama-3.1-8b-instant`، یا `https://generativelanguage.googleapis.com/v1beta/openai` با `gemini-2.5-flash`). اگر کلید وارد نباشد یا سرویس خطا دهد، ایجنت بدون آن کار می‌کند و چیزی از دست نمی‌رود.

## فیلتر متن
دو گروه کلیدواژه لازم است: موضوع دانش‌بنیان (دانش‌بنیان، شتاب‌دهنده، اینیشیو…) و موضوع مالی (تسهیلات، وام، فراخوان، اعتبار، حمایت، ضمانت‌نامه، معافیت…). متن‌های صرفاً خبری و آگهی‌ها (استخدام، وبینار، کارگاه، دوره، بوت‌کمپ، مسابقه، فروش ویژه) رد می‌شوند. نرمال‌سازی نیم‌فاصله، ی/ک عربی و ارقام فارسی انجام می‌شود تا کلیدواژه‌ها درست بخورند.
